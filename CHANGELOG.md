## v0.9.1 - 2026-11-25
First public release.

Tested on Linux (amd64), macOS (arm64) and Windows (amd64).

go-run is three packages, each a leaf that imports no other:

- [`exit`](exit/README.md): a checked table of the ways a command can end, each with a closing word, a sentence, the line to type next and an exit code.
- [`runlog`](runlog/README.md): an append-only journal of the runs of a program that change something, one JSON line per update.
- [`version`](version/README.md): which build a program is, from what Go records in the binary and what your build stamped over it.

### Changed
* The README and the package READMEs are rewritten: one line for each package, what each is built on, adds and leaves to the calling program, and every module go.mod requires with what it is for. Security problems go through GitHub's private vulnerability reporting. No Go file changes.
* go.mod requires github.com/birdtable/go-testkit v0.3.1, for tests only; a program that imports go-run links none of it.
* go.mod requires github.com/birdtable/go-files v0.16.1, in place of v0.13.0.
