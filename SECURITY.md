# Security

## Reporting a vulnerability

Please report a vulnerability privately, never in a public issue. GitHub's private vulnerability reporting is the only route.

Use [GitHub's private vulnerability reporting](https://github.com/birdtable/go-run/security/advisories/new):
open the **Security** tab of the repository and choose **Report a vulnerability**. Describe the class of
problem and the shortest way to see it, and the Go version and system you saw it on.

We will answer within a few days, tell you whether we take it as a vulnerability, and agree a date for
the fix and its release with you before anything is made public.

## Supported versions

The latest minor version of go-run gets security fixes. Older minors do not: upgrade to the latest.
